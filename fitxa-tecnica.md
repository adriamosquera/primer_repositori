# Fitxa tècnica: Instal·lació de Visual Studio Code
 
## Objectiu
 
Instal·lar Visual Studio Code i comprovar que funciona correctament.
 
## Materials
 
- Ordinador
- Connexió a Internet
- Navegador web
 
## Procediment
 
1. Obrir el navegador.
2. Entrar a la pàgina oficial de Visual Studio Code.
3. Descarregar l'instal·lador.
4. Executar l'instal·lador.
5. Finalitzar la instal·lació.
 
### Comanda utilitzada
 
```bash
code .
```
 
## Comprovacions
 
- [ ] Visual Studio Code s'obre correctament.
- [ ] Es pot crear un fitxer nou.
 
## Incidències i solucions
 
| Incidència | Solució |
|---|---|
| No s'instal·la el programa | Tornar a descarregar l'instal·lador |
| No s'obre l'aplicació | Reiniciar l'ordinador |
